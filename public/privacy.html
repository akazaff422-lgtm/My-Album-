Privacy Policy

JABED VAO Album Studio. Last updated: November 2026.

What this app is

JABED VAO Album Studio is a private, personal media album. It is built and used by one person (the owner, JABED VAO) to keep their own videos, photos, audio files and similar media organized in folders.

What data we use

The app connects to the owner's own Google Drive account using the limited drive.file permission. With this permission the app can only create, read and delete the files it created itself, inside a folder named "JABED Album". It cannot see any other file in the Google account.

What we store

  • The media files the owner uploads, stored in the owner's own Google Drive and in the owner's own cloud storage.
  • A list of folder names and links to those files, stored in the owner's own database.

Sharing and selling

We do not sell, rent or share any data with anyone. The app has no advertising and no analytics or tracking.

Google user data

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to store and play back the owner's own media inside the album.

Deleting your data

The owner can delete any file, folder or the whole album from the website at any time. Access can also be removed at any moment from the Google Account permissions page (myaccount.google.com/permissions).

Changes

If this policy changes, the updated version will be published on this page.
